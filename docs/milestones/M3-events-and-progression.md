# M3：事件与长期成长

状态：实现与自动验证完成；真实 Telegram 流程和 Discord 连接预检已通过，待 Discord 玩家流程

## 玩家结果

联盟会因当前状态收到可选择的事件；角色可以开始技能训练，并在离线期间持续成长。

## 交付内容

- EventOccurrence、事件模板、选项和结果；
- 查询待处理事件及解决事件用例；
- Discord component 与 Telegram inline keyboard 的事件展示；
- 事件超时和默认选项；
- 至少一个由采矿结果触发的事件链；
- 技能定义、角色技能状态和训练 TimedAction；
- 一个会影响采矿效率或可用行动的技能结果；
- 内容定义版本与存档兼容策略的首版说明。

## 验收场景

1. 达到明确条件后，联盟只产生一个对应事件实例。
2. 玩家选择有效选项后结果只应用一次，旧按钮再次点击不会重复生效。
3. 事件超过期限后执行默认结果，并无法再手动选择。
4. 技能训练跨服务重启正常完成。
5. 技能结果对后续采矿产生可测试、可解释的影响。
6. Discord 和 Telegram 对相同事件产生等价领域结果。

## 设计约束

事件模板不能执行任意 Python 代码。M3 先使用受控的条件和效果注册表；只有在真实内容需求证明不足后，再评估 DSL 或脚本系统。
