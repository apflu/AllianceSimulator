# 产品愿景

## 一句话描述

Alliance Simulator 是一个由玩家通过聊天平台管理联盟、安排长期行动并处理动态事件的持久化异步游戏。

## 玩家身份

MVP 中，一位真实玩家拥有并控制一个联盟。联盟中的角色是模拟成员，不等同于 Discord 或 Telegram 用户。身份与联盟分开建模，以便未来支持跨平台账号绑定、共同管理联盟或联盟间合作。

## 核心体验

玩家每天进行少量但有意义的决策：

1. 查看联盟当前状态和新发生的事情。
2. 安排成员、舰船和资源执行采矿、训练、探索或战斗行动。
3. 等待现实时间推进，离线期间游戏仍然继续。
4. 收到完成通知、风险报告或剧情事件。
5. 通过选项决定联盟的长期发展方向。

## 设计原则

- **异步优先**：不要求玩家持续在线，也不依赖高频操作。
- **决策重于点击**：交互次数少，但选择应改变资源、风险或发展方向。
- **平台无关**：平台负责收发消息，游戏规则不认识 Discord、Telegram 或 HTTP。
- **服务器权威**：客户端展示状态，所有合法性判断和结算发生在后端。
- **数据驱动内容**：舰船、技能、材料和事件定义与运行时状态分离。
- **可解释结果**：玩家能够知道行动为什么成功、失败，以及数值如何变化。

## 非目标

首个版本不尝试实现：

- EVE Online 的完整经济、舰船和战斗公式；
- 实时飞行、空间坐标或客户端级战斗操作；
- 大规模联盟 PvP；
- 玩家自由交易市场；
- 图形化 Web 客户端；
- 微服务拆分。

## 知识产权边界

玩法可以受 EVE Online 启发，但公开发布前应使用原创名称、文本、图像和数据，避免复制受保护素材，并单独检查适用的商标与粉丝内容政策。
