# MVP 范围

## MVP 成功定义

一位新玩家可以在 Discord 创建联盟，开始一次采矿行动，退出并等待，随后收到可靠的完成通知并看到资源增加；同一游戏核心之后可由 Telegram 完成等价操作。

## 必须包含

- 外部平台身份映射到内部玩家身份；
- 创建联盟，重复创建请求保持幂等；
- 一个初始角色、一艘初始舰船和一个采矿模块；
- 联盟状态与库存查询；
- 一个固定地点和一种可采集材料；
- 开始、到期结算和查询采矿行动；
- 服务重启后仍能结算逾期行动；
- 完成通知使用事务性发件箱，允许安全重试；
- Discord 入口；
- Telegram 对等入口；
- 一个带选项和明确结果的联盟事件；
- 单元、集成和适配器契约测试。

## 暂不包含

- 多星系旅行、自由选择目标和动态异常空间；
- 舰船装配模拟与完整伤害系统；
- 多角色技能队列；
- 多玩家共同控制同一联盟；
- 付费、排行榜、赛季和玩家交易；
- Web UI。

## MVP 指标

- 同一个平台交互重复投递不会重复发放资源。
- 服务停止后重新启动，所有到期行动最终都会且只会结算一次。
- Discord 与 Telegram 对相同应用命令产生等价的领域结果。
- 游戏核心测试无需连接平台 API 即可运行。
- 从新玩家到完成第一次采矿不需要人工修改数据库。
