# ADR-0003：IM 与 Web 采用平台适配器

- 状态：已接受
- 日期：2026-07-29

## 背景

Discord、Telegram 和 Web 的命令格式、按钮、身份 ID、响应时限和消息编辑能力不同。如果平台对象进入游戏核心，规则会重复实现，并且后续很难增加入口。

## 决策

每个平台实现入站和出站适配器：

- 入站适配器验证平台请求、解析身份和幂等键，然后调用应用用例；
- 应用层返回平台无关的结果或展示模型；
- 出站适配器把展示模型渲染为消息、按钮或 HTTP JSON；
- 平台身份通过 `PlatformIdentity` 映射到内部 `Player`；
- 相同用例通过契约测试验证 Discord 与 Telegram 的领域结果一致。

## 后果

- 游戏核心不能导入 discord.py、aiogram 或 FastAPI；
- 平台特有能力可以改善展示，但不能改变基础规则；
- 新增 Web 入口不需要复制游戏逻辑；
- 账号绑定策略可以独立演进。
